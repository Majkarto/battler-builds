# Thousand Banners

Bitwy oddziałów w klimacie fantasy. Dowodzisz trzema oddziałami naraz i razem z drużyną walczysz o wzgórze na środku mapy. Do wyboru ludzie, elfy, krasnoludy, trolle i nieumarli. To wczesna wersja testowa.

## Uruchomienie

**Windows:** rozpakuj zip i odpal `Thousand Banners.exe`. Gdy Windows zaprotestuje, kliknij „Więcej informacji”, potem „Uruchom mimo to”.

**Linux:** rozpakuj zip, potem `./ThousandBanners.x86_64` (gdyby nie chciało ruszyć: `chmod +x ThousandBanners.x86_64`).

W lobby kup oddziały w drzewku, przeciągnij je z koszar do składu (5 slotów) i kliknij **Find game**. Gdy w lobby meczu są co najmniej 2 osoby, po 3 minutach mecz rusza sam, albo wcześniej, gdy większość kliknie **Start now**.

Postęp z wersji „Battler” przenosi się sam przy pierwszym uruchomieniu.

## Sterowanie

| Klawisz | Co robi |
|---|---|
| LPM, 1–5 | wybór oddziału (Shift dodaje, Ctrl+A wszystkie) |
| PPM | ruch, a na wrogu atak (strzelcy strzelają) |
| Alt+PPM | strzelcy idą wręcz |
| WASD, Q/E, kółko | kamera |
| T | zdolność oddziału |
| H | utrzymaj pozycję |
| K | harcowanie (strzelcy odchodzą, gdy wróg podejdzie) |
| G / V / L | łucznicy: wstrzymaj ogień / salwa / stromy tor |
| TAB | tabela wyników |
| ESC | ustawienia, poddanie się |
| F8 | zapis raportu z błędu (trafia do `Dokumenty\Thousand Banners Reports`) |

## Znane problemy

- Gdy host wyjdzie, mecz kończy się wszystkim.
- Balans jest w trakcie prac, szczególnie nowych zdolności i nieumarłych.
- Ghule i upiorna jazda nieumarłych mają jeszcze tymczasowy wygląd.
- Teksty w grze są po angielsku.
